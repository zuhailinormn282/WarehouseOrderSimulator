# Warehouse Order Simulator - WMS Stock Allocator

A warehouse management system simulator that processes orders, checks stock availability, and updates inventory in real-time.

## Features
- SQL Server database for persistent storage
- Complete order processing workflow
- Inventory management with stock validation
- Transaction logging for audit trail
- Receipt generation

## Technologies
- C# (.NET 8)
- SQL Server
- Microsoft.Data.SqlClient

## How to Run
1. Create database using the SQL script
2. Update connection string in appsettings.json
3. Build and run the console application
